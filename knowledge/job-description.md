# Target Job Description Focus
**Role:** Boomi Senior Developer
**Experience Required:** 5 to 8 years IT (2+ years software delivery/integration).
**Core Responsibilities:** End-to-end Boomi implementation, leveraging best practices, automation, and guiding junior developers. Requirement Analysis, Environment Setup, Process Design, Deployment, & Hypercare.

**Critical Technical Requirements:**
*   **Target Connectors:** Workday (Crucial), SAP, Salesforce (SFDC), Oracle, JDE, SuccessFactors.
*   **Integration Patterns:** Real-time, Scheduled, Batch, ETL, Event-based, Boomi Pub/Sub model.
*   **Protocols & Formats:** REST, SOAP, S/FTP/S, HTTP/S, File I/O, XML, JSON, CSV, EDI.
*   **Advanced Boomi:** Document flow, document cache, complex error/exception handling.
*   **Scripting:** Groovy or JavaScript. Relational Database and SQL skills.
*   **API Management:** Equivalent experience to Apigee/Mashery.
*   **Certifications:** Professional Integration Developer Certification mandatory.
